HomeSync

Task management self-hostato per la casa, usato ogni giorno da due persone.Self-hosted task management for the house, used every day by two people.

Il problemaThe problem

Le app di task management tengono i dati su server altrui. In casa serviva uno strumento privato, senza abbonamenti e con poca manutenzione: due utenti fissi e compiti ricorrenti.Task management apps keep your data on someone else's servers. At home I needed something private, with no subscription and little maintenance: two fixed users and recurring tasks.

Cosa ho costruitoWhat I built

Backend FastAPI asincrono con SQLite in modalità WAL: nessun database da amministrare. Il frontend è React senza build step, caricato direttamente nel browser; i container girano con healthcheck. L'app è installabile come PWA, con task ricorrenti, punteggi e storico condivisi tra i due utenti. Il repository pubblico è una copia ripulita dai dati personali; la versione in uso gira sul server di casa.Async FastAPI backend with SQLite in WAL mode: no database to administer. The frontend is React with no build step, loaded straight in the browser; the containers run with healthchecks. The app installs as a PWA, with recurring tasks, shared scores and shared history for the two users. The public repository is a copy cleaned of personal data; the version in use runs on the home server.

Tech Stack

FastAPI React (no-build) Babel standalone Docker SQLite / WAL Nginx
