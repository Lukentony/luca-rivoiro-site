Broom

Le pulizie di casa in un'app Android, con i dati sul telefono e nessun server da accendere.Household cleaning in an Android app, with the data on the phone and no server to turn on.

Il problemaThe problem

HomeSync sta sul server di casa e lo uso dal browser. Per le pulizie di tutti i giorni volevo la stessa cosa su un'app del telefono, che funzionasse senza accendere il server.HomeSync runs on my home server and I use it from the browser. For everyday chores I wanted the same thing as a phone app that works without turning the server on.

Cosa ho costruitoWhat I built

Ho ripreso HomeSync e l'ho ricostruito come app Android, in JavaScript con React e Capacitor. I dati stanno sul telefono: nessun server e nessun account. Il documento è salvato in locale con Automerge e c'è un backup automatico nella cartella Documents.I took HomeSync and rebuilt it as an Android app in JavaScript with React and Capacitor. The data stays on the phone: no server, no account. The document is stored locally with Automerge, with an automatic backup to the Documents folder.

La sincronizzazione tra due telefoni oggi è a mano: passo il documento da un telefono all'altro con il menu di condivisione di Android e unisco le modifiche. Aggiornare l'app da una versione all'altra richiede ancora una reinstallazione, e sto cercando la causa. La sync automatica sulla stessa WiFi, con i due documenti che si fondono, è il prossimo passo: prevista, non ancora fatta.Syncing two phones is manual for now: I pass the document from one phone to the other through Android's share menu and merge the changes. Updating the app from one version to the next still needs a reinstall, and I'm looking for the cause. Automatic sync over the same WiFi, with the two documents merging, is the next step: planned, not built yet.

Ruolo: progetto personale, repository pubblico da luglio 2026. Test automatici su logica, storage, notifiche e controllo aggiornamenti; la pipeline compila l'APK.
