GIS / Adattamento e deployment

Orizzonte Sole

Un fork del progetto di Luca Malinverno, adattato e ospitato per l’eclissi del 12 agosto 2026, con dati del terreno del Piemonte in locale.

Fork · Demo conclusa

Il problema

Ospitare il progetto sul mio server per condividerlo con gli amici dal telefono, riducendo la dipendenza dalla rete per i dati del terreno in Piemonte.

Il mio contributo

Il calcolo originale è di Luca Malinverno. Ho adattato il deploy Docker, precaricato i dati DEM del Piemonte e aggiunto cache delle risposte, controllo della concorrenza e un’interfaccia più comoda sul telefono.

Prove disponibili

Gli adattamenti per il deploy sul mio server sono documentati in ADR-002, nel repository.

Uso e limiti

La demo è stata spenta dopo l’eclissi. Il repository resta disponibile per chi vuole esaminare o riprendere il lavoro.

Tecnologie e riferimenti

React / FastAPI / MapLibre / Docker
