Agenti AI / Supervisione

superPi

Una UI locale per seguire più conversazioni di coding agent: attività dei tool, eventi, stato e note in un unico posto.

Applicazione sperimentale Linux

Il problema

Quando lavoro con più agenti, devo mantenere visibili contesto, attività e decisioni senza perdere il filo tra le conversazioni.

Il mio contributo

Ho costruito un’interfaccia web locale per seguire le conversazioni Pi. Il server Node.js trasmette gli eventi via SSE e conserva note per ogni conversazione.

Prove disponibili

Il README spiega come avviarlo su Linux e descrive le opzioni di accesso. Il comando npm test esegue i controlli offline, senza contattare un provider AI.

Uso e limiti

È sperimentale e non è una sandbox. Gli agenti possono usare i permessi dell’utente del sistema operativo: non va esposto a reti non fidate e Tailscale non sostituisce l’autenticazione.

Tecnologie e riferimenti

Node.js / Linux / Server-Sent Events
