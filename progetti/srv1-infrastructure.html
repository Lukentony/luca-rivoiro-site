srv1 Infrastructure

Un server in casa, su hardware consumer. Più servizi, rete controllata e backup con copia fuori sede.A server at home, on consumer hardware. Several services, a controlled network, and backups with offsite copies.

Il problemaThe problem

Sul server di casa girano servizi che uso ogni giorno. Se salta un backup o un container, me ne devo accorgere io; se lascio esposto un accesso, devo correggerlo io.Services I use every day run on my home server. If a backup or a container fails, I have to notice it; if I leave an access path exposed, I have to fix it.

Cosa ho costruitoWhat I built

Ho separato i servizi pubblici dagli accessi amministrativi. Per gli accessi privati uso Tailscale con Headscale, per il firewall UFW. I backup hanno una copia fuori casa e verifico la destinazione. Ho scritto una dashboard che mostra risorse, container, eventi e stato dei backup: continuo a mantenerla perché è il posto da cui controllo il server.I separated public services from administrative access. For private access I use Tailscale with Headscale; UFW handles the firewall. Backups have an offsite copy and I check the destination. I wrote a dashboard that shows resources, containers, events and backup status: I still maintain it because that's where I check the server.

Tech Stack

Linux Ubuntu Docker UFW Tailscale Headscale rsync

Il codice e i dettagli del server restano privati. Posso spiegare come organizzo accessi, backup e controlli, senza pubblicare la configurazione.The code and server details stay private. I can explain how I handle access, backups and checks without publishing the configuration.
