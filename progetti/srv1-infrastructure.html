srv1 Infrastructure

Un server in casa, su hardware consumer. Più servizi, rete controllata e backup con copia fuori sede.A server at home, on consumer hardware. Several services, a controlled network, and backups with offsite copies.

Il problemaThe problem

Un server in casa deve restare su mentre ospita più servizi. Non ci sono SLA né un reparto IT: accessi, aggiornamenti, dati e guasti se li prende chi lo gestisce.A home server has to keep running while it hosts several services. There are no SLAs and no IT department: access, updates, data and failures are on whoever runs it.

Cosa ho costruitoWhat I built

Il server gira su hardware consumer e ospita i servizi che uso ogni giorno. La rete è divisa tra servizi pubblici, accessi amministrativi e una rete overlay privata: UFW per il firewall e Tailscale con control plane Headscale per gli accessi. I backup hanno una copia offsite e controlli sulla destinazione. La dashboard raccoglie risorse, servizi, container, eventi e stato dei backup; l'ho scritta io e continuo a mantenerla.The server runs on consumer hardware and hosts the services I use every day. The network is split between public services, administrative access and a private overlay network: UFW for the firewall, Tailscale with a Headscale control plane for access. Backups have an offsite copy and destination checks. The dashboard collects resources, services, containers, events and backup status; I wrote it and still maintain it.

Tech Stack

Linux Ubuntu Docker UFW Tailscale Headscale rsync

Codice privato, nessun repository pubblico: l'ambiente reale non si espone. Sono capacità che documento e uso ogni giorno, non certificazioni.Private code, no public repository: the real environment stays off the site. These are capabilities I document and use daily, not certifications.
