AI Guardian Lab

Middleware Python open source tra un agente LLM e la shell. Controlla i comandi prima che vengano eseguiti: allowlist dei binari, un motore regex contro gli offuscamenti, il controllo che il comando c'entri con il task e una verifica LLM per i casi dubbi. Basta che una fase abbia un dubbio e il comando non passa. Gira in container con privilegi ridotti e in dry-run. È un prototipo di ricerca: quello che sta fuori dalla pipeline non è coperto e non c'è una sandbox forte.Open-source Python middleware between an LLM agent and the shell. It checks commands before they run: allowlist for binaries, a regex engine against obfuscation, a check that the command matches the task, and an LLM check for doubtful cases. If any phase has doubt, the command doesn't go through. It runs in containers with reduced privileges and in dry-run. It's a research prototype: whatever falls outside the pipeline isn't covered, and there's no strong sandbox.
