Backend / Web application

HomeSync

Household tasks, recurring chores and shared history. FastAPI backend with data on our home server; SQLite avoids a separate database service.

Used daily by two people

The problem

Share recurring chores between two people, see who is responsible and keep a history without a subscription service.

My contribution

I developed a FastAPI backend and React interface for tasks, scores and history. I chose SQLite in WAL mode for the household workload, without a separate database server to administer.

Available evidence

My partner and I use it every day. The public repository is a copy cleaned of personal data; it shows the project, not our household information.

Usage and limits

Designed for a two-person household. SQLite reduces the services to manage, but backups, updates and data care remain necessary.

Technologies and references

FastAPI / React / SQLite / Docker
