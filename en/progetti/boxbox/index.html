Data pipeline / PWA

BoxBox

A PWA for MotoGP fantasy with friends. Adaptive updates, transparent scores and optional LLM-based news analysis.

Private MotoGP league

The problem

For our fantasy league, I wanted to distinguish qualifying, sprint, race and bonus points rather than only seeing the total.

My contribution

I built a PWA and Node.js pipeline that updates data hourly and more frequently during race weekends. It rebuilds scores and renews the API session through a headless browser. Pipeline errors trigger a Discord notification.

Available evidence

The public README documents adaptive schedules, session renewal and optional LLM-based news sentiment analysis. The app serves our private league.

Usage and limits

The pipeline depends on external services. API or authentication changes require integration updates; automation does not eliminate this maintenance.
